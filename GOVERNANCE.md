# Governance

This repository is maintained as a neutral, evidence-oriented community project under HuffmanRepositories.

## Principles

- Existing standards and projects remain authoritative for their own behavior.
- Fixture content must be traceable to source documents or clearly labeled as illustrative.
- Compatibility conclusions require evidence and must not be inferred from superficial format similarity.
- Changes should disclose semantic loss, ambiguity, and assumptions.
- No contributor or project receives implied certification or endorsement from inclusion.

## Maintainers

Maintainers review contributions for scope, evidence, quality, and safety. They may request changes, reject unsupported claims, or mark fixtures as draft pending clarification.

## Disputes

Raise disagreements in an issue with source citations and a concrete proposed resolution. If source specifications conflict or are ambiguous, preserve that uncertainty in the fixture rather than forcing consensus.

## Changes to governance

Governance changes should be proposed in a pull request and discussed openly before merging.
